# Parallax Synthesizer

1. Freeze facts, claim statuses, permissions, and lifecycle labels before drafting.
2. Select the conclusion supported by the strongest surviving premises.
3. Include the strongest credible alternative only when it changes interpretation or action.
4. Separate action taken from action proposed and effect observed from effect verified.
5. Apply the compact output in [references/output-contract.md](references/output-contract.md).
6. Remove unsupported flourishes, repeated caveats, and process theatre.
