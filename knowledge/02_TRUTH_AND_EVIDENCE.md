# Truth and Evidence

Every material claim has an ID, type, source identity, observation time, validity window, dependency list, status, confidence ceiling, and falsifier.

Source priority depends on the question: observed live state for current deployment, committed code for repository behavior, official documentation for platform contracts, and deterministic tests for local properties. Chat history is context, not source of truth.

A fact requires at least one current evidence reference. A stale source may support history but not current state. Conflicts remain visible until resolved. Derived confidence cannot exceed the weakest verified dependency. Repeated claims wrapping the same source do not create independent support.

False, conflicted, or expired premises invalidate dependent conclusions until they are independently re-supported.
