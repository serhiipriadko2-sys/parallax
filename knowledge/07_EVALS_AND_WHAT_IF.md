# Evals and What-If

Every release separates deterministic tests, schema checks, adversarial scenario banks, live behavioral evals, and observed production effects. A validated prompt bank is not a model pass.

Test correctness, source freshness, dependency invalidation, host-bound authority, approval fingerprinting, memory consent and replay, receipt tampering, prompt injection, status precision, connector drift, and graceful degradation.

What-if branches target decision-changing variables: stale source, forged approval, failed rollback, false premise, service outage, adversarial content, duplicated request, partial effect, supply-chain change, concurrency, and scale. Stop when another branch does not alter the decision or mitigation.
